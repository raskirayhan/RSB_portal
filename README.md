# Rayhan Special Batch (RSB_portal)
> SSC ও HSC বিজ্ঞান বিভাগের (Physics, Chemistry, Math, Higher Math, Biology, ICT) স্পেশাল প্রাইভেট কোচিং ম্যানেজমেন্ট ও সিকিউর লার্নিং প্ল্যাটফর্ম।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Core Features)

1. **ইউনিফাইড অথেনটিকেশন ও ডুয়াল-ডিভাইস অ্যান্টি-পাইরেসি (Dual-Device Control):**
   * স্টুডেন্ট প্রতি সর্বোচ্চ ২টি ডিভাইসে (যেমন: ১টি ফোন + ১টি ল্যাপটপ) একই সাথে লগইন থাকবে।
   * ৩য় ডিভাইসে লগইন করলে সবচেয়ে পুরনো সেশনটি স্বয়ংক্রিয়ভাবে বাতিল (FIFO eviction) হয়ে যাবে।
   * ৬ ডিজিটের সিকিউর ইমেইল OTP ভেরিফিকেশন ও পাসওয়ার্ড রিসেট।

2. **পাবলিক ল্যান্ডিং পেজ ও ফ্রি ডেমো ক্লাস:**
   * লগইন ছাড়াই ভিজিটররা ২-৪ মিনিটের কনসেপ্ট ডেমো ক্লাস (ভেক্টর, অর্গানিক মেকানিজম, লজিক গেট, ক্যালকুলাস) দেখতে পারে।
   * ব্যাচ সময়সূচী, মাসিক ফি এবং বিগত ব্যাচের শিক্ষার্থীদের রিভিউ ও সাফল্য।

3. **ডাইনামিক স্টুডেন্ট প্রোফাইল ও অফলাইন QR ব্যাজ:**
   * ১০০% প্রোফাইল পূরণ না হওয়া পর্যন্ত স্টাডি ভল্ট নোটস ডাউনলোড লক থাকবে।
   * ইউনিক স্টুডেন্ট আইডি (যেমন: `RSB-26-001`) ও ক্রিপ্টোগ্রাফিক QR কোড জেনারেট হয়।
   * প্রিন্ট ও মোবাইল স্ক্রিনে প্রদর্শনযোগ্য ডিজিটাল আইডি কার্ড।

4. **অটোমেটেড মান্থলি পেমেন্ট ও বিলিং ইঞ্জিন:**
   * প্রতি মাসের ১ তারিখে `node-cron` স্বয়ংক্রিয়ভাবে সক্রিয় শিক্ষার্থীদের ইনভয়েস তৈরি করে।
   * bKash/Nagad ম্যানুয়াল Transaction ID (TrxID) সাবমিশন ও অ্যাডমিন ১-ক্লিক অনুমোদন।
   * অনুমোদনের পর স্বয়ংক্রিয় অফিসিয়াল সাইন করা হাফ-A4 সাইজ PDF মানি রিসিট।
   * মাসের ১০ তারিখ সফট রিমাইন্ডার এবং ১৫ তারিখের পর বকেয়া থাকলে নোটস ডাউনলোড সাময়িক লক।

5. **স্মার্ট স্টাডি ভল্ট ও অ্যান্টি-লিক ডাইনামিক PDF ওয়াটারমার্কিং (`pdf-lib`):**
   * বিষয়ভিত্তিক (Physics, Chemistry, Math, Biology, ICT) ও অধ্যায়ভিত্তিক লেকচার শিট, সূত্রের শিট ও ক্যাডেট কলেজ CQ প্রশ্নব্যাংক।
   * স্টুডেন্ট ডাউনলোড বাটনে ক্লিক করলেই সার্ভার রিয়েল-টাইমে প্রতিটি পেজের ব্যাকগ্রাউন্ডে ডায়াগোনালি শিক্ষার্থীর নাম, আইডি, ফোন ও ডাউনলোড টাইমস্ট্যাম্প ওয়াটারমার্ক বসিয়ে দেয়।

6. **টিচার-স্টুডেন্ট ফিডব্যাক ও অটো গার্ডিয়ান ডাইজেস্ট:**
   * রায়হান স্যার শিক্ষার্থীদের ব্যক্তিগত সবল ও দুর্বল দিক লিখে ফিডব্যাক দিতে পারেন এবং শিক্ষার্থীরা তাদের প্রশ্ন/ডাউট পাঠাতে পারে।
   * প্রতি মাসের শেষে অভিভাবকের ইমেইলে উপস্থিতি হার ও একাডেমিক অগ্রগতি রিপোর্ট পৌঁছে যায়।

7. **গ্যামিফিকেশন ও ইন-অ্যাপ সায়েন্স গেমস:**
   * ৪টি ইন্টারেক্টিভ সায়েন্স মিনি-গেমস: *Periodic Table Quick Match*, *Physics Formula Rush*, *Mental Math Sprint*, এবং *Science MCQ Battle*।
   * XP পয়েন্ট, ডেইলি লগইন স্ট্রিক, লাইভ ব্যাচ লিডারবোর্ড এবং ডিজিটাল ব্যাজ (যেমন: "Periodic Table Wizard")।

8. **সুপার অ্যাডমিন কন্ট্রোল রুম (রায়হান স্যার):**
   * এক্সিকিউটিভ অ্যানালিটিক্স ড্যাশবোর্ড (মোট কালেকশন, বকেয়া, সক্রিয় শিক্ষার্থী)।
   * পেন্ডিং bKash TrxID ১-ক্লিক অ্যাপ্রুভাল কিউ।
   * ওয়েবক্যাম বা ফাস্ট টেস্ট দিয়ে অফলাইন ব্যাচ QR কোড অ্যাটেনডেন্স স্ক্যানার।
   * নতুন লেকচার শিট ও ডেমো ক্লাস আপলোড।

## 🛠 টেক স্ট্যাক

* **ফ্রন্টএন্ড:** React 19, TypeScript, Vite, Tailwind CSS, Lucide React, Framer Motion, Canvas Confetti, HTML5-QRCode
* **ব্যাকএন্ড:** Node.js, Express.js (TypeScript), Modular MVC / Service Architecture
* **ডেটাবেস:** PostgreSQL + Prisma ORM (15 Relational Models)
* **সিকিউরিটি ও ক্রন:** JWT (Access + Device Refresh Tokens), `pdf-lib` (Dynamic PDF Watermarking), `node-cron` (Monthly Schedulers), `qrcode`

## 💻 রান করার নিয়মাবলী

### ১. ব্যাকএন্ড সার্ভার চালু করুন
```powershell
cd server
npm install
npm run prisma:push
npm run seed
npm run dev
# সার্ভার চালু হবে: http://localhost:5000
```

### ২. ফ্রন্টএন্ড ক্লায়েন্ট চালু করুন
```powershell
cd client
npm install
npm run dev
# ক্লায়েন্ট চালু হবে: http://localhost:5173
```

### ৩. অটোমেটেড টেস্ট স্যুট রান করুন
```powershell
cd server
npx tsx test-suite.ts
```
